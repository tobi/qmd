# Liquid

## Definition

Shopify's template language (born from the snowboard store), the first piece of the platform's narrow waist; recurs from 2006 to 2024.

## Timeline

> How Tobi framed this across appearances (date → source → framing note).

- **2006-11-27** — [[sources/2006-leo-laporte]] · `SRC-2006-11-27-001` — Early (Nov 2006) TV segment on Leo Laporte's Call for Help, months after Shopify's launch; Tobi demos the Liquid theme engine, frictionless two-page checkout, and crowdsourced internationalization.
- **2010-07-09** — [[sources/2010-mixergy]] · `SRC-2010-07-09-001` — 2010 Mixergy interview: the pricing-model pivot that 'truly launched' Shopify, the Snowdevil origin, discovering Ruby on Rails in 2004, and using the Typo blog engine to build an audience before launch.
- **2024-09-26** — [[sources/2024-liquid-weekly]] · `SRC-2024-09-26-001` — 2024 Liquid Weekly developer interview: the history of Liquid, Ruby/Rails, the Snowdevil origin, and Shopify's tech stack (Hydrogen, Polaris, Functions, WebAssembly).
