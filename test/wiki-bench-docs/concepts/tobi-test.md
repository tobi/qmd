# Tobi Test

## Definition

The "Tobi test" is Tobi's chaos-engineering habit of deliberately breaking things so the company learns to treat failure as ordinary. The origin he recounts: "I logged into our server farm and turned random services off… to make sure that we are not relying on memcache being up" — and the team named the practice after him. It seeded the "Thriving on Change" core value and a company littered with similar drills (closing the Ottawa office for a month; running a developer-conference day with no power in San Francisco).
